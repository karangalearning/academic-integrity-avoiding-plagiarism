# Academic Integrity & Avoiding Plagiarism

An interactive microlearning course designed for university students.

The course introduces key principles of academic integrity and helps learners recognise plagiarism, paraphrase effectively, and understand when sources should be acknowledged.

## Topics covered

- Academic integrity
- Recognising plagiarism
- Paraphrasing
- Citing and acknowledging sources
- Knowledge checks and practical scenarios

Created by Karanga Learning Studio.
